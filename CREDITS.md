# Credits

## Author

Both the original VegX 2.x XML Schema and this VegX 3.0 JSON Schema are authored by the **IAVS (International Association for Vegetation Science) Ecoinformatics Working Group**.

## Original VegX 2.x XML Schema

- **Version:** 2.0.6
- **Source:** [`vegx-standard/veg.xsd`](../vegx-standard/veg.xsd) and its companion `.xsd` files

## VegX 3.0 JSON Schema (this repository)

`vegx.schema.json` is a document-centric re-expression of the VegX 2.x information model: it covers the same concepts as the XML Schema but replaces normalised ID/IDREF references with nested JSON objects.

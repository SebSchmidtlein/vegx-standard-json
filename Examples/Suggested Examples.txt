Useful edge cases

After those work, produce a few deliberately awkward records:

Plot name containing accented characters
Species name containing × or an author citation
Zero cover versus missing cover
Plot without coordinates
Missing optional measurements
Decimal values using the app’s expected decimal separator
Same plot surveyed on two dates
Same individual tree surveyed on two dates
Use recognizable values such as plot PLOT-01, cover 23, height 4.5, and date 2026-08-06. Distinctive values make incorrect mappings immediately visible.

Export each project to both XML and, later, JSON. Keep a short note describing what was entered in Vegapp; the trio of input description, XML output, and expected JSON will form a strong conformance test suite. Start with examples 1–4, since they exercise the core model with little data-entry work.
